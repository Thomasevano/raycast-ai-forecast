# Issue tracker

- **Tracker:** GitHub Issues, repository `Thomasevano/raycast-ai-forecast`.
- **Tool:** `gh`. Verify the repository with `gh repo view --json nameWithOwner` before creating issues.
- Specs belong in issues. PRs implement linked issues, rather than acting as the request surface.
- Express genuine ticket dependencies with GitHub's native blocking links. Work blockers first.
- The maintainer owns merge. Creating a PR does not authorize merging or Raycast Store submission.
